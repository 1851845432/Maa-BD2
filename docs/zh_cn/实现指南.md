# 如何实现自己的游戏助手

基于 MaaFramework 快速开始文档，本指南将详细说明如何实现一个自己的游戏助手。

## 一、开发方案选择

MaaFramework 提供三种集成方案，根据您的需求选择：

### 方案一：纯 JSON 低代码编程（快速入门）

**适用场景**：快速入门、简单逻辑实现

**特点**：

- 零编码基础要求
- 通过 JSON 配置实现自动化流程
- 适合简单的点击、识别任务

**示例**：

```json
{
    "点击开始按钮": {
        "recognition": "OCR",          // 文字识别引擎
        "expected": "开始",            // 目标文本
        "action": "Click",             // 执行点击操作
        "next": ["点击确认图标"]        // 后续任务链
    },
    "点击确认图标": {
        "recognition": "TemplateMatch",// 图像模板匹配
        "template": "确认.png",        // 匹配素材路径
        "action": "Click"
    }
}
```

### 方案二：JSON + 自定义逻辑扩展（推荐）⭐

**适用场景**：需要复杂逻辑处理

**特点**：

- 保留 JSON 低代码优势
- 在 Agent 进程中注册自定义识别/动作模块
- 无缝衔接项目模板

**当前项目已采用此方案**，您可以在 `agent/my_reco.py` 和 `agent/my_action.py` 中扩展自定义逻辑。

### 方案三：全代码开发

**适用场景**：深度定制需求

**特点**：

- 完全通过代码控制
- 失去可视化编辑器等工具支持
- 不推荐，除非有特殊需求

## 二、资源准备

### 1. 文件结构规范

您的项目已经按照标准结构组织：

```
assets/
├── resource/
│   ├── image/                # 图像素材库
│   │   └── empty.png
│   ├── model/
│   │   └── ocr/              # 文字识别模型
│   │       ├── det.onnx
│   │       ├── keys.txt
│   │       └── rec.onnx
│   └── pipeline/             # 任务流水线
│       └── my_task.json
└── interface.json            # 项目接口配置
```

### 2. OCR 模型文件准备

**重要**：您需要下载 OCR 模型文件才能使用文字识别功能。

1. 下载 [ppocr_v5-zh_cn.zip](https://download.maafw.xyz/MaaCommonAssets/OCR/ppocr_v5/ppocr_v5-zh_cn.zip)
2. 解压到 `assets/resource/model/ocr/` 目录
3. 确保文件结构如下：

   ```
   assets/resource/model/ocr/
   ├── det.onnx
   ├── keys.txt
   └── rec.onnx
   ```

### 3. 图像素材准备

在 `assets/resource/image/` 目录下放置您的游戏截图素材：

- 使用无损原图缩放到 720p 后再裁剪
- 推荐使用工具获取截图：
  - VSCode 插件
  - MFA 小工具
  - 图片裁剪及 ROI 获取工具

## 三、编写任务流水线（Pipeline）

### 1. 基本任务定义

编辑 `assets/resource/pipeline/my_task.json`，定义您的任务流程：

```json
{
    "任务1_点击开始": {
        "recognition": "OCR",
        "expected": "开始",
        "action": "Click",
        "next": ["任务2_等待加载"]
    },
    "任务2_等待加载": {
        "recognition": "TemplateMatch",
        "template": "加载完成.png",
        "action": "Click",
        "next": ["任务3_执行操作"]
    },
    "任务3_执行操作": {
        "recognition": "Custom",
        "custom_recognition": "my_reco_222",
        "action": "Custom",
        "custom_action": "my_action_111"
    }
}
```

### 2. 常用识别引擎

- **OCR**：文字识别，需要 `expected` 字段指定目标文本
- **TemplateMatch**：图像模板匹配，需要 `template` 字段指定图片路径
- **Custom**：自定义识别，需要 `custom_recognition` 字段指定识别器 ID

### 3. 常用动作类型

- **Click**：点击操作
- **Swipe**：滑动操作
- **Custom**：自定义动作，需要 `custom_action` 字段指定动作 ID

## 四、自定义识别和动作

### 1. 自定义识别器

编辑 `agent/my_reco.py`：

```python
from maa.agent.agent_server import AgentServer
from maa.custom_recognition import CustomRecognition
from maa.context import Context

@AgentServer.custom_recognition("my_reco_222")
class MyRecongition(CustomRecognition):
    def analyze(
        self,
        context: Context,
        argv: CustomRecognition.AnalyzeArg,
    ) -> CustomRecognition.AnalyzeResult:
        # 在这里实现您的识别逻辑
        # argv.image 是当前截图
        
        # 示例：调用其他识别引擎
        reco_detail = context.run_recognition(
            "OCR",
            argv.image,
            pipeline_override={"OCR": {"expected": "目标文本"}},
        )
        
        # 返回识别结果
        return CustomRecognition.AnalyzeResult(
            box=(x, y, width, height),  # 识别到的区域坐标
            detail="识别详情"            # 可选的详细信息
        )
```

### 2. 自定义动作

编辑 `agent/my_action.py`：

```python
from maa.agent.agent_server import AgentServer
from maa.custom_action import CustomAction
from maa.context import Context

@AgentServer.custom_action("my_action_111")
class MyCustomAction(CustomAction):
    def run(
        self,
        context: Context,
        argv: CustomAction.RunArg,
    ) -> bool:
        # 在这里实现您的动作逻辑
        
        # 示例：执行点击
        click_job = context.tasker.controller.post_click(100, 200)
        click_job.wait()
        
        # 示例：动态调整任务流
        context.override_next(argv.node_name, ["下一个任务"])
        
        return True  # 返回 True 表示成功
```

### 3. 注册自定义模块

在 `agent/main.py` 中导入您的自定义模块：

```python
import my_action
import my_reco
```

这样 Agent 服务器启动时会自动注册这些模块。

## 五、配置项目接口（interface.json）

编辑 `assets/interface.json` 配置您的项目：

### 1. 基本信息

```json
{
    "interface_version": 2,
    "name": "您的项目名称",
    "description": "项目描述",
    "version": "1.0.0"
}
```

### 2. 控制器配置

配置如何连接您的游戏：

```json
{
    "controller": [
        {
            "name": "安卓端",
            "type": "Adb",
            "display_short_side": 720
        },
        {
            "name": "桌面端",
            "type": "Win32",
            "win32": {
                "class_regex": ".*",
                "window_regex": "游戏窗口标题",
                "screencap": "PrintWindow",
                "mouse": "PostMessageWithCursorPos",
                "keyboard": "PostMessageWithCursorPos"
            }
        }
    ]
}
```

### 3. 资源路径配置

```json
{
    "resource": [
        {
            "name": "官服",
            "path": ["./resource"]
        }
    ]
}
```

### 4. 任务列表配置

```json
{
    "task": [
        {
            "name": "普通任务",
            "entry": "MyTask1"  // 对应 pipeline 中的任务名
        },
        {
            "name": "选项任务",
            "entry": "MyTask2",
            "option": ["任务选项1"]
        }
    ]
}
```

### 5. Agent 配置（启用自定义模块）

取消注释 Agent 配置：

```json
{
    "agent": {
        "child_exec": "python",
        "child_args": [
            "./agent/main.py"
        ]
    }
}
```

## 六、运行和调试

### 1. 检查资源文件

运行资源检查脚本：

```bash
python check_resource.py assets/resource
```

### 2. 使用通用 UI 运行

1. 下载 [MaaDebugger](https://github.com/MaaXYZ/MaaDebugger/releases) 或使用其他支持 ProjectInterface 协议的 UI
2. 打开 UI，选择您的项目目录
3. 连接设备（ADB 或桌面窗口）
4. 选择任务并运行

### 3. 调试选项

在项目根目录会生成 `config/maa_option.json`，可配置：

```json
{
    "logging": true,           // 保存日志到 debug/maa.log
    "save_draw": false,        // 保存图像识别可视化结果
    "stdout_level": 2,         // 控制台日志等级（0-7）
    "save_on_error": true,     // 任务失败时保存截图
    "draw_quality": 85         // 可视化结果 JPEG 质量
}
```

### 4. 查看日志

- 控制台输出：根据 `stdout_level` 设置
- 日志文件：`debug/maa.log`
- 错误截图：任务失败时保存在 `debug/` 目录

## 九、常见问题

### 1. OCR 识别失败

- 检查 OCR 模型文件是否正确放置
- 检查图片质量和分辨率
- 调整识别区域（ROI）

### 2. 模板匹配失败

- 确保图片素材基于 720p 缩放
- 检查图片路径是否正确
- 调整匹配阈值

### 3. Agent 连接失败

- 检查 Python 环境是否正确
- 检查 `agent/main.py` 是否正确导入自定义模块
- 查看 `debug/maa.log` 中的错误信息
